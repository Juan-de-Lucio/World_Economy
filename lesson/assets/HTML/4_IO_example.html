Interactive Input–Output Table

This example shows 2 countries (C1, C2), each producing 2 products (Prod1, Prod2). Rows represent the origin of the output, and columns represent the destination (intermediate inputs in other countries/products, or final demand).

Instructions: Enter numerical values in each cell to represent intermediate inputs (row → column) or final demand. The table will automatically sum each row, showing total output on the right.
